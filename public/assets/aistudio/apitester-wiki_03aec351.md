# What is Api Tester?

[Permalink: What is Api Tester?](https://github.com/rdhmuhammad/apitester/wiki#what-is-api-tester)

* * *

Over the course of 3 years as software engineer, I noticed that during development phase,
there are certain repetitive task that don't really help me grow as an engineer.
They consume time, break focus, and often feel like problems that
should be solved once and automated. Especially during integration test, for some features,
it's easy to spend 5–10 minutes just preparing request payloads before you can
even begin testing.

Those minutes may seem small, but they add up quickly. I'd rather spend that time
learning new things, understanding the business domain, improving the product,
or solving real engineering challenges, instead of repeatedly filling out JSON
payloads.

With this project, I want to build a workflow that takes care of repetitive tasks like generating
Postman collections, preparing test payloads, and integrating with agentic AI
where it actually adds value.
Some features span multiple APIs and require a series of requests before they
can be properly tested. Instead of manually setting everything up every time,
the goal is to automate as much of the process as possible, making integration
testing faster, simpler, and less painful.

# What Is Api Tester For?

[Permalink: What Is Api Tester For?](https://github.com/rdhmuhammad/apitester/wiki#what-is-api-tester-for)

Api Tester is designed to do the following:

- [ ]  Generate api docs to collection file from source code controller
- [ ]  Provide GUI which visualize the collection file, and utilized it for integration test across the team.
- [ ]  Support payload autofill with mock data and defined collection variable.
- [ ]  Add an MCP server that can convert test case spreadsheets into actual API tests. It will also help with tasks such as creating APIs,
generating payloads, testing specific workflows, and automating other repetitive development activities.
